# Textures

The game paints its own textures at start-up. Drop an image here to replace one.
Use `.jpg`, `.png` or `.webp` (tried in that order). Tileable images work best.

| File name     | Used for                                     | Suggested size |
| ------------- | -------------------------------------------- | -------------- |
| `ground.jpg`  | The earth around the ritual circle (tiled 10×) | 512–1024 px    |
| `stone.jpg`   | The standing stones and rubble               | 256–512 px     |

The paths are set in `SCENE.textures` in `js/config.js`.
